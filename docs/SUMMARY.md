  - **النسخة الحرفية الكاملة:** اجتازت جميع الدروس `L01..L10` بنسب تطابق `٩٩٫٣٪ – ١٠٠٫٧٪` مع التفريغ الصوتي المجرد (`٤٩,٨٩٤` كلمة شرحية).
